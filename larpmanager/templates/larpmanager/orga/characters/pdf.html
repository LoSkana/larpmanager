Page layout Choose the format in the field "PAGE SIZE", and the empty space left on each side in "PAGE MARGIN" (in centimeters). Nothing else is needed: the layout of the sheets is built automatically from these options.
If you prefer to define it yourself, write your own rule in the field "CSS":
@page { size: A4; @frame content_frame { margin: 2cm; } }
What you write by hand always wins: the options above are applied only for what your own rule does not define.
Header and footer Activate "HEADER" to show on top of each page the name of the organization, the name of the character, and the name of the event. Activate "FOOTER" to show on the bottom the name of the event, and the number of the page. The space for them is reserved automatically, and the text of the sheet is moved down (or up) accordingly.
If you want a different content, write your own frames in the field "CSS", pointing them to your own elements:
@page { [... other stuff ...] @frame header_frame { -pdf-frame-content: header_content; top: 1cm; } }
(Please note that this command needs to be inside the @page part! You can use "<pdf:pagenumber>" and "<pdf:pagecount>" for the page numbers)
Page background Upload the image in the field "BACKGROUND IMAGE". It will be applied automatically to every page of the generated sheets, expanded to cover the whole page (for the best result, use an image with the same ratio of the chosen page size, for example 1:1.414 for A4).
If instead you want to control it yourself, upload the image on the {% trans "Utils" %}, copy the internal link, and place the following in the "CSS":
@page { [... other stuff ...] background: url('#internal_link#'); }
(Please note that this command needs to be inside the @page part!)
Fonts Make sure the font has format TTF (Truetype), otherwise find some online tool to convert it!

Upload the font file in the field "TITLE FONT" to apply it to the name of the character and to the titles, and in the field "TEXT FONT" to apply it to all the other text.
If instead you want to apply it only to some elements, upload the font on the {% trans "Utils" %}, copy the internal link, and place the following in the "CSS":
@font-face { font-family: '#name#'; src: url('#internal_link#'); }
#char_name { font-family: '#name#'; }
(Change #name# with something appropriate! Common tags: #char_name for the character name, #char_title for the character title, h2 for the paragraph titles)
Colors Choose them in the fields "TITLE COLOR" (name of the character and titles), "TEXT COLOR" (all the other text), "LINK COLOR" and "HIGHLIGHT COLOR" (text in bold). Leave a field empty to keep the standard color.
For anything else, write it in the "CSS":
a { color: #desiredcolor; }
